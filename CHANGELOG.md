# Change Log

All notable changes to the "classroom-extension" extension will be documented in this file.

## 0.5.0 (2026-08-04)
- Align repo features behavior with Classroom50.
- Support student repository permission in assignment acceptance.

## 0.4.0 (2026-07-29)

- Locked assignments are no longer shown in the student assignment list.
- Assignments with release date are hidden until the release date passes, except for assignments the student has already accepted.

## 0.3.0 (2026-07-28)

- Feedback PR is created when assignment is accepted.

## 0.2.0 (2026-07-23)

- Group assignment support.
- Show classroom names (not only slug).
- Support empty repository assignments.

## 0.1.0 (2026-07-17)

- Support for unlisted classrooms.
- Accept flow now writes the autograde workflow with the repository's real default branch.

## 0.0.9 (2026-07-02)

- Initial release.
